# 节制天下兵马：无地头衔管理器 0.4.4

## 推荐搭配

这两个 Mod 可以分别订阅和单独启用。使用《无地头衔管理器》0.4.4 与《住所庄园管理大师》1.2.1（或含相同页面的更新版）时，两种加载顺序都提供头衔管理器的标记 B 和大师的住所快捷操作。单开时显示已启用作品提供的按钮。两套人物互动的头衔标记分别保存。 [住所庄园管理大师（Steam 工坊）](https://steamcommunity.com/sharedfiles/filedetails/?id=3819185353) · [无地头衔管理器（GitHub）](https://github.com/apo-so/ck3-landless-title-manager)

面向 CK3 1.20.1.2，提供简体中文界面。独立运行，不要求同时安装《军政分离》或《兼领军事修会》。

## 开始游戏

把压缩包中的 `01wuditouxianguanliqi` 文件夹和 `01wuditouxianguanliqi.mod` 文件放到 CK3 用户目录的 `mod` 下。在启动器启用本 Mod 后完整启动游戏。首次安装或更新包括新制度的版本时需要冷启动。

右键人物，打开「无地头衔管理（天下兵马）」。选「创立无地头衔」进入图鉴，被右键的人物就是拟持有人。普通头衔和住所使用位阶下拉；有独立原生组织的类型遵从制度位阶。「直接创立」打开小回执，「创立并编辑属性」会打开新头衔。要编辑已有头衔，在同一菜单上方选中该头衔，再选「编辑所选头衔属性」。

在原生头衔详情页点原生图钉。编辑器中的 A 始终是实际编辑对象。纹章与颜色可分别从不同标记头衔选取，也可用 A 的原生自定义页面。

对尚无头衔的人物，同一菜单提供创立和属性编辑选项。创建回执也可直接打开新头衔。独立管理总览暂未开放。

## 图鉴中的制度

| 类型 | 创立后得到什么 |
|---|---|
| 普通无地 | 公爵至霸权的独立头衔。首府在首授前设置，以便引擎接受无地属性。伯爵不能走普通动态头衔构造器。高于原主头衔时，新头衔会成为主头衔，并可能改变封臣关系。 |
| 住所 | 为所选位阶创建带住所的头衔，保留拟持有人的原政体；同级和低级保留原主头衔，升级主头衔须再次确认。住所类型取自菜单；独立宅邸与原生住所分别处理。 |
| 游牧、冒险者 | 所选位阶的头衔挂真实毡帐或营地，提交后核对政体、应保留的主头衔或已确认的晋升。游牧公爵使用可选位阶的住所构造器，没有原版专用游牧伯爵的 nomad 标记。 |
| 教区 | 原生教区、辖县和持有人。标记伯爵领或男爵领可指定地点；空地不够时尝试由拟持有人首府分区。无法组成辖区时不给普通头衔代替。 |
| 军事修会、修会 | 原生修会组织、相应类型、领袖和租地。军事修会与隐修会分开。先使用明确标记且适格的空闲男爵领，未指定时在双方领内选址。单独持有驻地的市长或男爵先把产权交给当地伯爵，建团失败时回授，成功后修会取得租约。 |
| 佣兵团 | 新建暂未开放。当前引擎公开脚本不能即时建立真实公司及其特殊头衔。可对现有团长使用“无地头衔管理”中的“剥夺所选头衔”取得既有团号。 若另一名在世申请人也认领该团号或公司，旧申请会保留在「待核对」。 |
| 宗教领袖 | 把头衔登记给拟持有人的信仰。若已有领袖，首次点击只显示原领袖头衔，再次确认才改立；其他信仰的登记不随之更换。天主教封建持有人在登记时转为教会制，领地法律随之更换，读档后保留。 |
| 枢机 | 在有教会选举人机制的信仰创建选举席位，使席位登记与持有人相对应。同一人不能重复占席，主持选举的本信仰领袖不能同时占其席位。 |

## 费用、兼容与续档

创立预览显示公爵等位阶的费用和威望，沿用管理器的游戏规则。只有返回的新对象、持有人、位阶及必需的制度关系核对通过后才结算。旧佣兵申请可在对应人物的佣兵词条核对。团号已交付时保留现有团长和名额。

保留原版或未知来源住所载体的禁毁。编辑器的转让是独立二次确认操作。指定头衔的继承规则只作用于 A；原版规则已满足时保留原法，需要单独指定时使用本 Mod 的头衔专用继承法。

分割继承是领地法。原生允许为单个头衔指定性别、单一继承人或选举规则。编辑器将分割继承标为领地法。

本 Mod 对原版头衔详情 GUI、政体变化中的游牧头衔清理，以及枢机失效清理有定向适配。同系列 Mod 不需要联用。联用时关注同名原版覆盖与加载顺序。建议在保有原存档的前提下使用本版；正式包不含测试存档、脚本探针或外部控制程序。

与其他自定义政体联用时，若双方都改写 NGovernment.GOVERNMENT_TYPES，兼容文件须同时保留双方的政体标识。本版在 1.20.1.2 原版 20 项后追加 sltm_residence_government。
更多创建结果与异常情况见 [创立时会发生什么](docs/创立与发布验收.md)。

选择高于现主头衔的普通或住所头衔时，图鉴显示将被替代的主头衔；第一次点击核对，再次点击同一创立按钮才执行。原头衔由原人物继续持有。
