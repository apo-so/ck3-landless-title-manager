## 开始游戏

把压缩包中的 `01wuditouxianguanliqi` 文件夹和 `01wuditouxianguanliqi.mod` 文件放到 CK3 用户目录的 `mod` 下。在启动器启用本 Mod 后完整启动游戏。首次安装或更新包括新制度的版本时需要冷启动。

右键人物，打开「无地头衔管理（天下兵马）」。选「创立无地头衔」进入图鉴，被右键的人物就是拟持有人。普通头衔和住所使用位阶下拉；有独立原生组织的类型遵从制度位阶。「直接创立」打开小回执，「创立并编辑属性」会打开新头衔。要编辑已有头衔，在同一菜单上方选中该头衔，再选「编辑所选头衔属性」。

在原生头衔详情页点原生图钉。编辑器中的 A 始终是实际编辑对象。纹章与颜色可分别从不同标记头衔选取，也可用 A 的原生自定义页面。

对尚无头衔的人物，同一菜单提供创立、属性编辑和授予已标记头衔。创建回执也可直接打开新头衔。独立管理总览暂未开放。

## 图鉴中的制度

| 类型 | 创立后得到什么 |
|---|---|
| 普通无地 | 公爵至霸权的独立头衔。首府在首授前设置，以便引擎接受无地属性。伯爵不能走普通动态头衔构造器。高于原主头衔时，新头衔会成为主头衔，并可能改变封臣关系。 |
| 住所 | 为所选位阶创建带住所的头衔，保留拟持有人的原政体；同级和低级保留原主头衔，选择更高位阶后可直接创立。住所类型取自菜单；独立宅邸与原生住所分别处理。 |
| 游牧、冒险者 | 所选位阶的头衔挂真实毡帐或营地，提交后核对政体、应保留的主头衔或已确认的晋升。游牧公爵使用可选位阶的住所构造器，没有原版专用游牧伯爵的 nomad 标记。 |
| 教区 | 原生教区、辖县和持有人。标记伯爵领或男爵领可指定地点；空地不够时尝试由拟持有人首府分区。无法组成辖区时不给普通头衔代替。 |
| 军事修会、修会 | 原生修会组织、相应类型、领袖和租地。军事修会与隐修会分开。标记男爵领后就在该地尝试，实际租约由游戏决定。未标记男爵领时在双方领内选址。单独持有驻地的市长或男爵先把产权交给当地伯爵，建团失败时回授，成功后修会取得租约。 |
| 佣兵团 | 新建暂未开放。当前引擎公开脚本不能即时建立真实公司及其特殊头衔。可对现有团长使用“无地头衔管理”中的“剥夺所选头衔”取得既有团号。 若另一名在世申请人也认领该团号或公司，旧申请会保留在「待核对」。 |
| 商会 | 在「通用 → 商会头衔」创建伯爵级家族商会与商会住所。首次成为统治者的人物采用商人政体，已有商会可直接查看。 |
| 宗教领袖 | 把头衔登记给拟持有人的信仰。若已有领袖，首次点击只显示原领袖头衔，再次确认才改立；其他信仰的登记不随之更换。天主教封建持有人在登记时转为教会制，领地法律随之更换；1.21.0.3 的伯爵级商人样本同样转为教会制。让他人先登记宗教领袖再转授的样本也未保住商人政体。 |
| 枢机 | 给所选人物尝试创立枢机头衔。创立结果显示当前选举权，选举人名单可能在过日后更新。 |

## 已知政体边界

非统治者获授军事修会与修道骑士团的样本分别正确成为对应修会政体。已有封建、行政、冒险者、共和国及公爵级游牧样本保留原政体。

伯爵级商人、部落和游牧接收更高等级骑士团的已测样本仍变为对应修会政体。代码本来就由临时团长先持有，再授予目标；把创办人也换成他人、分阶段转授及多种转让方式仍未解决这些样本。本版保留已知问题，不生成额外补救头衔，也不据此认定所有低等级角色、信仰及特殊头衔都会如此。宗教领袖的教会制转换另见上表。

## 费用、兼容与续档

创立预览显示公爵等位阶的费用和威望，沿用管理器的游戏规则。只有返回的新对象、持有人、位阶及必需的制度关系核对通过后才结算。旧佣兵申请可在对应人物的佣兵词条核对。团号已交付时保留现有团长和名额。

保留原版或未知来源住所载体的禁毁。编辑器的转让是独立二次确认操作。指定头衔的继承规则只作用于 A；原版规则已满足时保留原法，需要单独指定时使用本 Mod 的头衔专用继承法。

分割继承是领地法。原生允许为单个头衔指定性别、单一继承人或选举规则。编辑器将分割继承标为领地法。

本 Mod 对原版头衔详情 GUI、政体变化中的游牧头衔清理，以及枢机失效清理有定向适配。同系列 Mod 不需要联用。联用时关注同名原版覆盖与加载顺序。建议在保有原存档的前提下使用本版；正式包不含测试存档、脚本探针或外部控制程序。

与其他自定义政体联用时，若双方都改写 NGovernment.GOVERNMENT_TYPES，兼容文件须同时保留双方的政体标识。本版保留 1.21 原版 21 项（含商人政体），再追加 sltm_residence_government。
更多创建结果与异常情况见 [创立时会发生什么](docs/创立与发布验收.md)。

选择高于现主头衔的普通或住所头衔时，选定位阶后点击一次即可创立。升为主头衔时，封臣关系可能随之变化。

直接授予：先在头衔页标记，再右键受领人，打开「无地头衔管理（天下兵马）」并选择「授予已标记头衔」。没有任何头衔的人也可以接受授予。

## 家族头衔
商会条目显示当前家族归属。当家主已持有相应家族头衔时，可主动建立支系后创立。共和国贵族沿用同一商会条目，先标记共和国领主的头衔，再选择共和国身份。住所条目中选择家族、东亚或日本庄园后，可选择伯爵级世族模式。

1.21.0.3 实测：商会与三种庄园之间的十二种交叉占用均可通过自愿分家处理。更新前已有的家族头衔和商会继续使用。无宫廷的流浪者首次创立世族时，会在发起人的宫廷准备庄园。共和国身份会改变政体和臣属，图鉴在提交前显示目标领主；成为贵族家族后可从同一条目查看头衔。

「住所头衔 → 商会住所」按选择的位阶创建动态头衔及原生商会住所。若要创立真正的家族商会，请使用「通用 → 商会头衔」。

无家族人物可以在「通用 → 商会头衔」选择「建立家族并创立商会」。只为拟持有人建家；已有家族者继续使用原来的创建或分家流程。

创立图鉴可拖动：按住窗口顶部的空白处拖动，松开后可继续选择或提交。
