# 无地封臣（人物）筛选触发器：P0 + P1 单字段触发器 + 总 AND 触发器。
# 约定：遍历 sltm_lvm_all_holders 时，候选人物为 this；筛选变量读 scope:sltm_lvm_filter_player。
# 每个单字段触发器默认 flag:all 时恒为真；任一非默认条件不满足即排除该候选人。
# 带“需实跑核对”的写法使用最可能的原版 trigger/scope 名称，待游戏内复核参数方向。

        scope:sltm_lvm_filter_player.var:sltm_lvm_hf_gender = flag:all

        AND = { scope:sltm_lvm_filter_player.var:sltm_lvm_hf_gender = flag:male is_female = no }
