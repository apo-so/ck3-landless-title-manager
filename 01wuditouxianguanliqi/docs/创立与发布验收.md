# 创立时会发生什么

右键预定持有人，在「无地头衔管理（天下兵马）」中选「创立无地头衔」进入图鉴。左栏能继续浏览，同一词条可出现在多个分类中。住所与位阶使用词条内的下拉列表。未指定外观时使用默认名称、纹章与地图颜色，建成后可进入属性编辑器，或使用头衔详情页的原生自定义按钮。

| 玩家遇到的情况 | 处理 |
|---|---|
| 第一次创建或再次点击 | 普通流程只对本次返回的对象结算一次。想再建一项，需要重新选词条。 |
| 为其他人物建立 | 图鉴右上角显示拟持有人，回执列出实际得到的头衔。原标记 B 可随时用于查看及选取来源。 |
| 有多座住所 | 新住所与返回的新头衔绑定。「原生默认住所」由游戏决定。原生或来源不明的住所载体受保护。 |
| 普通伯爵 | 普通动态头衔从公爵起。选择高于原主头衔的位阶会升为新主头衔，也可能改变封臣关系。带住所的伯爵另走原生住所构造器。 |
| 修会找不到租地 | 在原生头衔详情中标记空闲且可租的男爵领，再次选择词条。军事修会与隐修会各有原生组织和租地。市长或男爵单独持有的驻地先转交当地伯爵；建团失败时回授原持有人。 |
| 教区不可建立 | 可标记尚有可用辖县的伯爵领或男爵领。若人物首府已有教区，游戏还会尝试分区。 |
| 宗教领袖已有其人 | 第一次点击显示将替换的领袖头衔。换拟持有人、信仰或现任领袖都须重新确认。天主教封建人物登记后会转教会制并更换领地法律。 |
| 枢机无席可授 | 可建立席位的信仰须有教会选举人。现任领袖及已有席位的人不能重复占席。 |
| 想获得佣兵团头衔 | 新建暂未开放。可从现有团长实际持有的特殊头衔中选择团号并使用“剥夺所选头衔”。 |
| 旧佣兵申请 | 在对应人物的佣兵词条核对。可退还已证实未使用的名额。已交付的保留实际团号及团长，有争议的可保留现状结案。申请人已死亡时，旧档可能只剩队列或认领；清理这些记录并保留文化名额。 |
| 添加头衔法律 | 性别及单一继承人规则可单独设在 A。原生分割继承是领地法。转让另行确认。 |

安装与兼容见同目录上一级的 README。旧版接口文件描述各自当时的开发阶段，以本版图鉴和说明为准。

选择高于现主头衔的普通或住所头衔时，图鉴显示将被替代的主头衔；第一次点击核对，再次点击同一创立按钮才执行。原头衔由原人物继续持有。
