# v0.2.0 开发接口说明

这是脚本包装合同，不是原生引擎 API 或动态加载 JSON。所有公开包装从 actor CHARACTER scope 调用；GUI 使用 GetPlayer.MakeScope，事件 root 为 actor。不要从 title/domicile scope 直接调用公开包装。

## 创建

`sltm_create_open_effect = yes` 清除旧创建/编辑草稿，初始化新草稿并打开路线菜单。模板取 actor.var:sltm_lvm_selected_title（可空），持有人默认 actor。

草稿：sltm_create_kind=1普通/2独立宅邸/3当前政体；tier=1county/2duchy/3kingdom/4empire/5hegemony；preset=1普通/2跟随主继承人且禁自动宣称/3继承时销毁；holder为Character；template为Title；geography=1显式复制；appearance=1显式复制。住所路线忽略普通生命周期预设。文本由原生控制器写 sltm_workflow_name；未编辑默认文本是 flag:sltm_workflow_default_name，自定义文本通过 GetLocalizedText 读取，不把数字变量缺失当作默认名。

`sltm_create_commit_effect = yes` 消耗 pending，清旧输出，捕获旧 title/住所集合并构造一次。通用住所构造器内部授予，不补第二次授予。仅返回全新对象才配置/登记；核对实际 tier、holder、住所 owner/type、旧绑定后结算一次。部分输出保留，无自动重造/销毁。结果保存在 sltm_last_created_title、sltm_last_created_domicile、sltm_create_result（0无输出/1不完整/2即时检查符合）、sltm_create_cost_settled（是否处理结算路径）。before/after_default、before/after_primary 都是实际对象引用，不能用作强制默认切换。

`sltm_residence_ensure_effect = yes` 只搜索 actor 已持有且本 Mod 来源/原始绑定仍匹配的独立宅邸，找到即返回编辑；没有则打开显式创建。不会静默在全世界寻找/认领未知来源对象。

## 编辑

先设置 actor.var:sltm_lvm_selected_title，再调用 `sltm_edit_open_effect = yes`。它固定 sltm_edit_target，读取实际 holder/title_domicile/title_capital_county/de_jure_liege，产生 pending。`sltm_edit_read_capabilities_effect` 的 sltm_cap_* 是脚本路径可用性（0预留/1有路径/2普通载体限定），不是运行验收。

dirty 字段的变量不存在即保持。名称 sltm_edit_name=1输入/2reset；纹章 sltm_edit_coa=1随机/2复制，来源 sltm_edit_coa_source=Title；颜色 sltm_edit_color=1，独立来源 sltm_edit_color_source=Title。首府 sltm_edit_capital=CountyTitle，法理 sltm_edit_dejure=Title，住所位置 sltm_edit_province=Province；sltm_edit_building=1补全独立最低主楼。

规则 sltm_edit_definitive/dynasty/nomadic/heir/claims/landless/succession/invalid_heir/same_tier=1yes/2no，删除变量表示保持。后四项执行层复查非住所载体。反向及未来生命周期全部待实机，不以 sltm_requested_* 请求记录冒充原生 getter。

法律 sltm_edit_law_add / sltm_edit_law_remove=1男性优先/2平等/3女性优先/4仅男性/5仅女性/6长子/7幼子/8年长者/9分割。只调用明确字面量 add_title_law/remove_title_law，无费用/效果版本；不会 clear_title_laws。

`sltm_edit_apply_effect = yes` 复查固定目标的 holder/住所绑定，消耗 pending，只写 dirty 字段，刷新并打开回执。sltm 编辑不调用创建器和创建资源结算。字段输出 actor.var:sltm_edit_result_<field>：0保持/跳过、1实际读回符合、2已请求未验原生值、3失败。aggregate applied/failed/unverified 为计数；这些是运行时的输出合同，当前静态检查不表示已执行。

`sltm_edit_transfer_effect = yes` 使用 sltm_edit_target 和 sltm_edit_transfer=Character，消费编辑 pending，不提交其他草稿；仅普通非住所目标可执行，事务后读实际 holder。住所转让、政治操作和转换仍预留。

`sltm_open_exact_domicile_effect = yes` 从当前 selected title 取得 title_domicile，保存 sltm_open_title / sltm_open_domicile；独立 relay 再核对绑定，用 ToggleGameViewData 打开该对象，最后清 pending。它不设置 holder.domicile，也不保证改变原生默认。

## 来源与保护

本 Mod 新对象登记 sltm_created_title、sltm_schema_version=2；有实际住所时保存 sltm_origin_domicile。只在返回对象不属于创建前 title/住所集合时登记。其他 Mod 的标记不可认领。

公共 sltm_protected_domicile_title_trigger 覆盖实际 title_domicile、原生 noble_family/nomad 类型与历史本 Mod origin 绑定。旧两处销毁统一调用 sltm_guarded_destroy_effect；旧剥夺/授予及新生命周期/转让执行层都复查非住所条件。本版所有住所都禁毁；额外住所拆除尚未实现。

扩展字段必须分别登记 read/set/reverse/clear/verify 的证据与能力；32项状态见属性接口实现状态.json。新增字段不得在未 dirty 时默认写 no，不得调用编辑器重收创建费，也不得用字符串拼接执行任意效果。


## v0.3.0 会话与独立地理参数

公共入口仍接收操作者 CHARACTER。调用 sltm_create_open_effect 或 sltm_edit_open_effect 后，sltm_workflow_new_session_effect 递增操作者 sltm_workflow_revision，并保存数值 scope:sltm_workflow_session；后续事件继承该值。它只标识本 Mod 草稿，不能当作原生头衔修订号。直接调用 commit/apply/transfer 的调用者必须保留当前入口的保存值；不要为旧草稿重存当前号来绕过校验。过期事件只提供无写入关闭。

创建草稿 sltm_create_capital=TITLE(county)、sltm_create_dejure=TITLE、sltm_create_province=PROVINCE，三个字段独立，缺省表示不额外写入。模板及标记只是选择时的来源；提交不再从首府推导住所位置。法理对象须更高位阶，这是层级结构约束。逐项结果 sltm_create_result_capital/dejure/province：0未选、1实际读回符合、3未通过。选择了却失败时整体创建回执降为不完整，保留已输出对象而不自动重建/删除。

编辑 has_changes 只检查实际 dirty 字段（不包含供体、基线或独立转让目标）。keep 删除字段；不同字段互不清空。法律数码保持1–9；UI选择同项相反操作时移除旧操作，最后选择生效。直接写草稿的调用者也必须规范化同项增删，不能同时写入相同数码并宣称最后意图。执行先remove后add，再对两项都读取最终集合。计数最后重建：1→applied、2→unverified、3→failed，每字段只进一类；applied不再包含仅请求或失败。

证据：save_scope_value_as={name=... value=var:...} 有当前原版 test_events/debug.txt:597 和 decisions_events/tgp_decision_events.txt:494 调用；整条会话继承链属于原版构件组合，运行 NOT RUN。事件原生文本 controller 仍写操作者的固定文本键，尚未验证旧页输入是否污染新草稿，禁止报告完全隔离。需先做新增会话/文本验收再进一步定稿。来源不明住所保护和冻结列表/经济路径不变。

TEXT002：当前原版 events/_events.info:168–169 明确支持 widget.is_shown。两处文字控件已加入当前创建/编辑会话条件；是否对已显示旧页实时隐藏并阻止控制器写入仍须按上述文本用例实测，不宣称已验证。
