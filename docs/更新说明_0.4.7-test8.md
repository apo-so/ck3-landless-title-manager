CK3 1.21.0.3 · 0.4.7-test8

本次适配 CK3 1.21.0.3。无家族、无头衔的宾客也能成为第一代商人家主。

- **创立家族商会**　在「创立无地头衔 → 通用 → 商会头衔」选「建立家族并创立商会」，此人将成为家主，获得商会和住所。无头衔者以商人身份起家，已有领地的领主可尝试兼领。
- **分家与世族庄园**　家主已有商会或庄园时，其他成员可选「建立支系并创立」，原家主保有原头衔与住所。想创立伯爵级世族，在「住所头衔」选家族庄园、东亚庄园或日本庄园，再点「选择世族头衔」。
- **加入共和国**　先标记共和国领主持有的头衔，再在「商会头衔」中选「共和国贵族身份」。加入后，此人改用共和政体，成为该领主的封臣。已有家族商会可以沿用。
- **给动态头衔配商会住所**　在「住所头衔 → 商会住所」选择伯爵至霸权中的任一位阶，住所会绑定到新头衔上。人物原有的家族商会仍可单独持有。
- **向无头衔人物直接授予**　标记想转交的头衔，再右键受领人，选「授予已标记头衔」。没有任何头衔的宾客、已有头衔的领主和玩家自己都能使用这个入口。
- **修会与枢机**　标记男爵领即可指定修会尝试租赁的地点，神殿也可以选。枢机头衔放宽了创立条件，图鉴会显示受领人当前的选举权。
- **图鉴操作**　按住窗口顶部空白处即可拖动图鉴。创建比现有主头衔更高的普通无地头衔或住所头衔，选定位阶后点一次即可创立。
